# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/8a7c0ab9-e86b-46af-8811-ebf849a4aa24

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `_PI_KEY` in [.env.local](.env.local) to your  API key
3. Run the app:
   `npm run dev`
